# StudioBench — Project Page

Static project webpage for **StudioBench: Benchmarking Agentic Multimodal Large Language Models for Productive Audiovisual Creation**.

**https://openraiser.github.io/StudioBench/**

This orphan branch (`gh-pages`) serves the static site and its web-optimized media assets for GitHub Pages.

## Contents

- `index.html` — self-contained static page (inline CSS & progressive JS, zero external CDN dependencies)
- `assets/videos/` — web-optimized audiovisual highlight clips (`.webm` + `.mp4` + posters) directly excerpted from delivered 720p model films
- `assets/genres/` — 16:9 representative stills across all eight StudioBench video genres
- `assets/figures/` — paper figures and 7-model qualitative contact sheets (`PNG` + `WebP`) with `figures.manifest.json`
- `assets/logos/` — official icons for the seven evaluated MLLMs
- `assets/fonts/` — local `WOFF2` fonts (`Bricolage Grotesque`, `Work Sans`, `JetBrains Mono`) and licences
- `assets/brand/` — StudioBench vector mark
- `assets/social-card.png` — `1200x630` Open Graph preview card
